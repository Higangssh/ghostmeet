# MeetButler (formerly ghostmeet) — working notes for Claude

Local meeting recorder and transcriber, being renewed from ghostmeet into MeetButler:
a Tauri 2 desktop app for Windows and macOS that records the microphone and system
audio separately, captions live with whisper.cpp, and replaces the captions with a
final transcript after the meeting. Scope and roadmap: `requirements.md` (v2).

| Path | What |
|---|---|
| `crates/meetbutler-engine/` | spans (Silero on tract), blocklist, `PcmStore`, tail window, SQLite store, pipeline, `Recorder`, model cache, span decoder |
| `crates/meetbutler-audio/` | 16 kHz mono conversion, mic (cpal), system audio (ScreenCaptureKit; Windows WASAPI not yet) |
| `app/src-tauri/`, `app/ui/` | the desktop app; `app/README.md` lists models and manual checks |
| `bench/` | engine benchmarks on public speech (FLEURS) and synthetic audio |
| `legacy/` | v0.1: Chrome MV3 extension + Python FastAPI backend, tagged `v0.1.0` |

## Security — this is a PUBLIC repo handling private meeting audio

Treat every change as world-readable and every recording as personal data.

**Never commit:**
- `.env`, API keys, tokens, or anything resembling `sk-ant-…` (only `.env.example` with commented-out placeholders)
- `recordings/`, `*.webm`, `*.pcm`, `*.wav` — these are real meeting audio
- Real transcript or summary text, in code, tests, docs, commit messages, or issue/PR bodies
- `demo/` contents, screenshots, or GIFs that show real participants, names, or discussion
- Downloaded datasets or models (`bench/data/`). Benchmark results on public speech are fine.

The app keeps real meeting audio in its data folder (macOS:
`~/Library/Application Support/dev.sshlab.meetbutler/` — `meetbutler.db` and
`sessions/<id>/{mic,system}.pcm`). It is outside the repo; never copy anything from it in.

**Before every push**, not just every commit, run the scan below and report what it
found. `.gitignore` is a safety net, not a substitute for looking.

```bash
git status && git diff --staged                       # read these, do not skim
git grep -nIiE "C:\\\\Users|/home/[a-z]|/Users/[a-z]|AppData|[a-z0-9._%+-]+@[a-z0-9.-]+\.[a-z]{2,}"
git grep -nIiE "sk-ant-|ghp_|AKIA[0-9A-Z]{16}|-----BEGIN.*PRIVATE KEY"
git log --all --pretty=format: --name-only --diff-filter=A | sort -u \
  | grep -iE "\.env$|recordings/|\.webm$|\.pcm$|\.wav$|\.db$"   # history, not just HEAD
```

Expected hits, safe to ignore: the pattern lines in this file,
`legacy/.env.example:2` (`sk-ant-...`, a placeholder), and
`@2x` image names that look like an email (`128x128@2x.png`, `mascot@2x.png`) in
`app/src-tauri/tauri.conf.json`, `app/make-icons.swift` and `app/ui/*.html`.
Anything else is a finding.

**Grep does not read images.** Screenshots, GIFs, icons and the demo asset can show real
meeting content, names or faces that no text scan will catch. Look at them. Frames come
out with `av.open(path)` plus `frame.to_image().save(...)`. `assets/demo.gif` was checked
on 2026-08-02 and is a synthetic meeting (Alice Chen / Bob Smith / Charlie Park, emoji
avatars) — re-check if it is ever replaced. The app icons in `app/src-tauri/icons/` are
generated by `app/make-icons.swift` from the mascot in `assets/brand/` (checked
2026-10-20); regenerate them with the script, never edit them by hand.

The commit author email is public in every commit going back to the first one, and the
repo owner has decided that is fine. Do not raise it again.

**Test fixtures must be synthetic.** Generate audio programmatically or with the macOS
`say` voice (`bench/make_synth.sh`, `bench/make_replies.sh`, written into the ignored
`bench/data/`). A fixture checked in holds derived numbers only, like
`crates/meetbutler-engine/tests/fixtures/silero_synth.json` (VAD probabilities of
synthetic speech). Never check in a clip of an actual meeting.

**Do not weaken the local-only posture** — it is the project's core promise:
- The app opens no port. The window talks to Rust over Tauri IPC only, under a strict CSP
  and minimal capabilities. `app/src-tauri/tests/security.rs` checks this, including that
  no server, HTTP client or telemetry crate is built for a desktop target. Keep it passing.
- The Chrome companion extension (0.4) connects by Native Messaging, never a local port,
  and sends meeting metadata only, never audio.
- No telemetry, no analytics, no crash reporting — in the app and in its tooling
- The app never downloads anything on its own; models come from a user action
- The only permitted outbound call is a user-triggered summary request to a cloud LLM the
  user configured; the default is a local model
- Do not introduce third-party SaaS dependencies (Recall.ai, Deepgram, etc.)
- New crates: permissive licences only (MIT, Apache-2.0, BSD, Unlicense). Note the licence
  in the commit message.

`legacy/` keeps its own rules: bind `127.0.0.1` by default (its Docker image binds
`0.0.0.0` inside the container and compose publishes on the host loopback only — keep
both halves), and CORS stays scoped to extension and loopback origins, never `*`.

**Commit messages** describe the change, not the meeting. No customer names, no
internal project names, no pasted transcript excerpts.

## Design constraints

- **Long sessions are a requirement, not a nice-to-have.** Users asked for 4+ hour
  meetings. Per-pass cost must stay flat: audio lives on disk (`PcmStore`), live passes
  read a bounded tail window, and the final pass decodes span by span in chunks so its
  memory does not grow with the meeting. Any change that reintroduces "re-process the
  whole session" during the meeting is a regression.
- **Two passes.** Live captions (small model) are provisional; after Stop, the final
  pass (large-v3-turbo) replaces the session's whole transcript in **one transaction**.
  A failed or cancelled final pass leaves the live transcript as it was.
- **We cut the speech spans**, with the same function and values live and after the
  meeting: Silero v4 onnx on tract (threshold 0.3, min silence 0.5 s, min speech 0.25 s,
  max speech 25 s, pad 0.2 s). Not whisper.cpp's built-in VAD — its Silero v5 port lost
  whole utterances on real speech (`bench/results/RESULTS.md` §7).
- **Do not judge a VAD or engine change on synthetic speech alone.** v5 looked better on
  TTS and was worse on FLEURS. Run the slow tier, including `slow_vad`, against FLEURS.
- **Hallucination blocklist** drops a span only when it is under 2 s *and* contains a
  known subtitle credit. A short real reply ("네.", "감사합니다.") must survive; the slow
  tests guard this.
- **Load each model once per process** (`ModelCache`), never per session. Never keep a
  Metal model in a `static`: ggml aborts if one is alive at process exit. Every quit path
  goes through `AppState::shutdown` on `RunEvent::Exit` (stop recording, cancel the final
  pass, drop models).
- **Absolute timestamps** come from the sample cursor, not from per-chunk accumulation —
  speaker diarization will depend on them lining up. Segments carry their channel
  (`me` / `them`) and a speaker field that stays empty until diarization lands.
- **Segments are persisted as they are recognised**, not at the end of the meeting, so a
  crash costs at most the transcript of the newest window: up to `window_sec` of speech
  held back or not yet committed, plus the audio that arrived since the last pass. The
  audio itself is already on disk; a session a dead process left behind is marked
  interrupted on the next start.
- Recording is always visible: nothing records until the user presses Start, and the
  red indicator and elapsed time stay on screen while it does. Red is not a brand colour.
- Model output (transcripts, summaries) is untrusted text. Never put it into
  `innerHTML` unescaped.

## Dev

From the repository root:

```bash
cargo test --workspace                                     # no model, no network
cargo test -p meetbutler-engine --features whisper,silero --release \
  --test slow --test slow_vad -- --ignored --nocapture --test-threads 1
MEETBUTLER_MODELS=$PWD/bench/data/models cargo run -p meetbutler --release   # the app
cargo clippy --workspace --all-targets --features meetbutler-engine/whisper,meetbutler-engine/silero
cargo fmt --all --check
```

The slow tier uses models already in `bench/data/models` (or `MEETBUTLER_MODELS`) and
synthetic audio from `bench/make_synth.sh` / `bench/make_replies.sh`; the FLEURS reference
comes from `bench/silero_reference.py --fleurs`. It never downloads anything.

v0.1, from `legacy/`:

```bash
cd legacy && ../.venv/bin/python -m pytest tests/ -q && node --test tests/extension/shared.test.mjs
```

Capture and the window have no automated runtime coverage. Run the manual checks in
`app/README.md` on a real Mac (permissions, channels, caption delay, every quit path)
before calling a build good.

Default tests use fake decoders, fake VAD probabilities and in-memory audio sources so
the suite stays fast and offline. Keep it that way — no default test may need a model or
a network call.

## Testing discipline

TDD: write the failing test, watch it fail for the right reason, then implement. When a
test catches a bug, verify the test actually fails without the fix before moving on.
